# 🌌 SnoopInSpace
Astronomy exploration project.

---

## ✨ Vision

The goal of the project is to build an application for exploring and observing space through real astronomical data.

---

## 🏗️ Technology

### Back-End

- .NET 9
- ASP.NET Core Minimal API
- SQL Server
- Dapper
- JWT Authentication

### Front-End

- Angular
- TypeScript
- Custom CSS UI

---

## 🧠 Architecture

The project follows a modular Ports & Adapters architecture.

---

## 🚀 Current Status

Current implementation focus:

```text
V1 — Authentication & API foundations
```

Implemented so far:

- authentication foundations
- fake JWT generation for early development
- login/register flow
- in-memory adapters for early development
- initial integration test infrastructure

## 🗺️ Planned Features
