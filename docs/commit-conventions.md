# Git Commit Convention

## Format

```text
<emoji> <type>(scope): message
```

Example:

```text
✨ feat(auth): add login endpoint
🐛 fix(jwt): validate token expiration
📚 docs(readme): add project vision
```

---

## Emojis

| Emoji | Type     | Usage                    |
| ----- | -------- | ------------------------ |
| ✨     | feat     | New feature              |
| 🐛     | fix      | Bug fix                  |
| ♻️     | refactor | Code refactoring         |
| 📚     | docs     | Documentation            |
| 🧪     | test     | Tests                    |
| 🔧     | chore    | Configuration / tooling  |
| 🎨     | style    | UI / design              |
| 🚀     | perf     | Performance improvements |
| 🔥     | remove   | Remove code/files        |
